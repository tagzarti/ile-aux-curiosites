# ✅ Checklist adulte — avant de faire jouer l'enfant

À faire une fois sur la tablette, environ 10 minutes.

## Réglages de la tablette
- [ ] Volume média réglé à un niveau doux (le jeu ne dépasse pas ce volume).
- [ ] Voix française installée : Paramètres → « Synthèse vocale » (ou « Text-to-speech ») → moteur Google → langue **Français (France)**. Télécharge la voix pour qu'elle marche hors-ligne.
- [ ] Rotation automatique activée, tablette tenue **en paysage**.
- [ ] Optionnel : « Épingler l'application » (Paramètres → Sécurité) pour que l'enfant ne sorte pas du jeu par erreur.

## Accueil
- [ ] Lilo dort sur fond de nuit ; un toucher n'importe où la réveille.
- [ ] On entend un petit carillon, puis Lilo dit bonjour **en français**, lentement.
- [ ] Le jeu passe en plein écran.

## L'île
- [ ] Lilo dit : « Voici notre île ! Touche un endroit pour y aller. »
- [ ] Toucher Lilo (en bas à gauche) : elle sautille et répète la consigne.
- [ ] Toucher la mer : « plouf » + rond dans l'eau. Toucher l'herbe : petites étincelles.
- [ ] Toucher chacun des 6 lieux : Lilo annonce le lieu, puis fondu vers le lieu.
- [ ] Les créatures inventées se promènent ; les toucher leur fait faire leur cri.

## Forêt des Sons
- [ ] 1er toucher d'un buisson : il bruisse, un cri d'animal, puis Lilo pose une question.
- [ ] 2e toucher : l'animal sort, Lilo dit son nom et un petit fait.
- [ ] Toucher l'animal sorti : il sautille et refait son cri.
- [ ] Quand les 6 animaux sont sortis, ils se recachent et on peut rejouer.
- [ ] Aucun cri n'est effrayant ou trop fort.
- [ ] La maison (en haut à gauche) ramène à l'île.

## Jardin Musical
- [ ] Chaque fleur joue une note, chaque champignon un tambour.
- [ ] Glisser le doigt sur les fleurs les fait jouer l'une après l'autre (comme une harpe).
- [ ] Plusieurs doigts en même temps fonctionnent.
- [ ] Toucher le coquillage : il « respire ». Jouer quelques notes, puis attendre 4 secondes : les trois amis rejouent la chanson en dansant.
- [ ] Toucher les amis plus tard : ils rejouent la dernière chanson, même après avoir fermé le jeu.

## Cabane aux Mots
- [ ] Niveau 1 : chaque lettre dit son **son** (« mmm », pas « èm ») puis un mot exemple avec son dessin. **Écouter toutes les lettres une fois** : si une ne sonne pas juste, me le signaler.
- [ ] Niveau 2 : une lettre bleue + une lettre rose → le train dit la syllabe (« ma »).
- [ ] Niveau 3 : toucher les morceaux dans l'ordre construit le mot ; le dessin apparaît. Un morceau touché trop tôt se secoue seulement (pas d'échec).
- [ ] Niveaux 4 et 5 : chaque mot se touche ; le bouton « Lilo » lit mot par mot puis la phrase entière ; les flèches tournent les pages.
- [ ] Les niveaux suivants s'ouvrent tout seuls (ou depuis l'espace parent).

## Atelier des Créatures
- [ ] Toucher la tête / le corps / les pattes les change ; les pots changent la couleur ; les 4 boutons ronds changent le cri.
- [ ] L'étoile : la créature danse, crie, puis part ; on la retrouve sur l'île.

## Ciel des Couleurs
- [ ] Glisser un nuage sur un autre : rouge + jaune = orange, jaune + bleu = vert, rouge + bleu = violet.
- [ ] Toucher un nuage : il pleut, la fleur en dessous prend la couleur ; puis un arc-en-ciel (de jour).
- [ ] Toucher le soleil : la nuit tombe (étoiles) ; toucher la lune : le jour revient.

## Écuries de la Prairie
- [ ] La bulle au-dessus du poney montre son humeur (cœur, carotte, poussière, zzz).
- [ ] Glisser la brosse sur lui enlève la poussière ; le panier lui donne une carotte ou une pomme.
- [ ] Le panneau : petite promenade (il revient un peu sale) ; la paille : sieste quand il est fatigué.

## Séance et espace parent
- [ ] Maintenir le cadenas 3 s, résoudre l'addition : l'espace parent s'ouvre (un simple toucher ne fait rien).
- [ ] Mettre la durée à 10 min et jouer : la lumière devient dorée puis bleutée, Lilo prévient, puis dit bonne nuit et l'île s'endort.
- [ ] Rouvrir le jeu juste après : Lilo dort encore. « Nouvelle séance » dans l'espace parent permet de rejouer.
- [ ] Le journal montre ce que l'enfant a fait.

## Confort
- [ ] Aucun flash, aucune animation agressive.
- [ ] Rien ne bloque : on peut toujours toucher quelque chose et revenir à l'île.
- [ ] En mode avion, le jeu continue de fonctionner (seulement une fois installé via GitHub Pages).
